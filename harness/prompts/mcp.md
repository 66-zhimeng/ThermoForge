# MCP server 给外部 agent 的说明

ThermoForge 是数据中心暖通的物理-数据混合建模研究系统。所有能力都经这些工具，
每个工具返回统一信封：`ok` 为 false 表示工具级失败（不会抛异常），必须读 `ok`
而不是看有没有报错。有副作用的工具返回稳定 ID（`dataset@rev_NNNN` / `RG-` /
`H-` / `EXP-` / `VIEW-` / `model@version`）。

先调 `tf_status` 看当前进展，再决定下一步。

## 硬规矩

- **候选输入白名单是硬门禁**：派生量（由公式算出来的列）不能用来预测它的原料，
  否则是循环论证。本站的历史教训是 `load = current_percent × 9672 / 100`。
- **预处理规则的审批需要人在网页控制台完成**，这里没有审批工具。
- **建模不需要审批**：内置闭集之外的新函数形式走模型实验室——`tf_lab_submit`
  提交单文件模型代码，静态扫描 + 子进程五连检一过就是 `validated`，立刻能以
  `category=lab` + `hyperparameters.lab` 开实验跑真实数据；改模型就改源码重交
  （自动进新版本），走不通的版本用 `tf_lab_deprecate` 停掉。
- 实验按时间切分、子进程隔离执行、种子固定，同机重跑指标应逐位一致。
