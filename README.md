# ThermoForge

ThermoForge is an autonomous physics–data hybrid modeling research system for data-centric HVAC applications.

The project combines physical models, historical and real-time data, reproducible experiments, and deployable model packages. The current repository contains the system architecture and data/modeling contracts that define the MVP direction.
