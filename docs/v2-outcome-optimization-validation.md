## 已验证的行为

| 场景 | 结果与判定边界 |
|---|---|
| 达标后的自主结题 | 测试研究在第一次实验满足冻结的 validate 阈值、登记解释与限制后，进入报告和停止流程，只执行一次实验，不用完四次额度；由模拟 Codex 驱动，不是新模型质量试验 |
| 实验后取消 | 已结算指标、流程图、缺失发现/报告/停止决定均保留；系统事实汇总不会冒充智能体报告 |
| 暂停后取消、服务恢复 | 无活跃智能体也会更新检查点终态；重复结算不会再次增加实验数 |
| 文件导出故障 | 实验数据库记录仍有效，可重新导出；中途写入失败保留上一份完整清单及不可变制品，未重复训练 |
| Windows 深目录 | 底层文件读写支持超过传统路径长度限制的目录；对用户和清单仍返回普通绝对路径 |
| 紧凑读取 | 历史按游标、字段和 ID 读取；长消息正文与引用分别分页；成功回合完整收到后才确认，中断重读不漏内容 |
| 权限与大小 | 候选隔离和共享阶段边界保持；回合增量、消息和团队读取按 32KB 总预算分页，未投递证据继续保留 |
| 反馈诊断 | 包含实际 CPU 实验验证。使用真实 validate NMBE；不存在的训练指标、泛化差距和物理检查标明缺失，留出面哨兵内容不回传 |
| 用量记录 | 累计通知与回合结果去重，保存增量和工具耗时/响应字节；响应字节不等于 token，也不直接代表费用 |
